PACE Initiative

Portfolio dashboard for program status, descendants, and key results

This dashboard starts from ADO anchor item 11287400, finds work items that have a Related or Child link to that anchor, then looks up to 3 child levels below each direct item for descendant work items.

ADO source: Not configured yet. Open Admin settings to define the ADO item or backlog for this dashboard.

ADO pull rules

  • Anchor: work item 11287400 in Corporate Objectives.
  • Program Status criteria: relation type is Related or Child from the anchor item.
  • Descendant criteria: child depth is 1, 2, or 3 below a direct Program Status item.
